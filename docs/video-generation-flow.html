Video Generator: flow, models, and libraries

This page documents each of the four generation flows, the local speech model, optional AI illustrations, and what happens after you submit a job.

Speech always runs locally with Piper. Transcript-only visuals use local Pillow drawings when no Gemini key is entered. Gemini image generation is optional and runs only when a key and the user's consent are supplied. Whisper is not a text-to-speech model; it recognizes speech in audio.

Models and libraries

ComponentTaskExecution and license notes
Piper TTS: LJSpeech High (English female), Norman Medium (English male), Priyamvada Medium (Hindi female), and Pratham Medium (Hindi male) Converts the transcript, without translation, to a WAV narration file. Natural, calm, and upbeat presets change phoneme length/speaking pace only; they do not add emotional acting. Runs locally through ONNX Runtime. The English LJSpeech and Norman datasets are public domain. The Hindi Priyamvada and Pratham model cards specify CC BY-NC-SA 4.0; those voices are for non-commercial use only. Check current model cards and conditions before publishing.
Pillow Normalizes uploaded images and draws or animates looping scenes for transcript-only videos when Gemini is not selected. Runs locally. The no-key stick-figure fallback does not send the transcript to an image provider.
Gemini 3.1 Flash Lite Image (optional) Generates still illustrations for transcript-only videos; Pillow adds motion and FFmpeg assembles the video. Requires the user's per-job key and explicit consent. Sends the transcript and optional character reference to Google. The current app creates six scenes, or eight with a character reference. This image model is not a TTS model.
Flask Web form, upload validation, background jobs, status and result endpoints. Python web framework; timestamped job logs and status are saved under output/<job-id>/job.json so completed or partial results can be recovered after a restart.
Browser Canvas + XMLHttpRequest Resizes still images before upload and reports progress. Videos are streamed to Flask in sequential 8 MB chunks, with a configurable total file-size limit. Runs in the browser; does not call an AI service. Chunking keeps each request small but does not increase the host's available disk space.
FFmpeg + ffprobe Fits or crops visuals, reads audio duration, encodes H.264/AAC MP4, and creates the looping GIF. FFmpeg errors are included in the job log. Runs locally on the server.

Could a Hugging Face model replace Gemini?

Yes, but the listed models are large diffusion/flow image generators, not small language models. The collection includes FLUX.1 [schnell] (12B parameters, 1–4 inference steps, Apache 2.0 after accepting its Hugging Face access conditions), AuraFlow v0.3 (7B, beta; its example uses CUDA and 50 steps), and PhotoMaker V2 (a character-identity adapter that needs an SDXL base model, rather than a standalone generator). Review each model's current card and license before use.

The current Render Docker image is a CPU-oriented Python image with no PyTorch, Diffusers, or GPU. Downloading and running 7B–12B image models there would be slow or exceed its available memory. To use one without a hosted model key, run the model on a machine with a suitable GPU and install its weights locally. Hugging Face Inference Providers can run models remotely, but require a Hugging Face token and are pay-as-you-go. The app does not currently integrate these Hugging Face image models.

Whisper is speech-to-text, not text-to-speech

Whisper recognizes speech and produces text (ASR). It cannot turn a transcript into spoken audio. This app's Piper TTS remains the appropriate local model for transcript → narration. Whisper could be added separately for an audio → transcript feature; it is not a replacement for Piper.

What happens after Generate

  1. The browser optimizes selected still images using Fit or Fill. Video files are split into sequential 8 MB chunks and assembled by Flask before generation.
  2. Flask validates the transcript and settings, stores the media, creates a background job, and returns its ID.
  3. The page polls the job status and displays timestamped server-side log entries; status/logs are also saved to disk for recovery.
  4. Piper synthesizes the narration. The app reads its duration with ffprobe.
  5. The selected visual mode draws local scenes, optionally requests Gemini still illustrations, or prepares uploaded images/video. Existing-audio mode uses ffprobe to time visuals to the audio.
  6. FFmpeg encodes the selected profile and creates a 15-second looping GIF preview (4 fps, 360 pixels wide). Audio-led image videos use 24 fps; uploaded-video mode uses 30 fps. The page shows previews and download links.

Hosted deployment

The repository includes a Dockerfile and Render Blueprint. Use Deploy on Render to create a hosted service; Render provides its URL after the first build. The Blueprint uses a free instance and caps each video at 512 MB. Uploads are chunked at 8 MB per request, but free-instance storage is temporary and limited. Use a paid instance with a persistent disk for durable outputs or larger workloads, and set DATA_DIR to the disk mount path. The public app has no user login; anyone with its URL can submit jobs.
